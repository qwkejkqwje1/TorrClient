# TorrClient — портативная сборка

Переносимая версия программы (демон + веб-интерфейс + десктоп-оболочка Wails + движок TorrServer).

## Запуск

| Способ | Действие |
| ------ | -------- |
| Десктоп | двойной клик по `app\build\bin\TorrClient.exe` или `start_desktop.bat` (оболочка сама запустит TorrServer на `127.0.0.1:8090` и демон на `127.0.0.1:8099`) |
| Браузер | `start_web.bat` — запускает `torrclient.exe`, который сам откроет `http://127.0.0.1:8099` |

Остановка всех процессов: `stop_all.bat`.

## Структура

```
TorrClientPortable/
  torrclient.exe                 <- демон (веб-интерфейс вшит в exe, Go embed)
  torrclient.json                <- конфиг: профили TorrServer, плееры, папки (в т.ч. кэша и постоянных данных)
  userdata.json                  <- избранное и закладки (папка постоянных данных)
  viewed.json                    <- отметки просмотра (папка постоянных данных)
  tmdb-cache.json                <- кэш постеров и оценок (папка кэша; можно удалять)
  torrclient.log                 <- журнал работы (папка кэша; можно удалять)
  TorrServer-windows-amd64.exe   <- движок торрентов (TorrServer)
  main.go, go.mod                <- исходники демона
  web/                           <- исходники интерфейса (app.js, style.css, index.html)
  app/                           <- исходники десктоп-оболочки (Wails) + сборка TorrClient.exe
  downloads/  watch/             <- папки загрузок и наблюдения (создаются автоматически)
  README.md
```

## Портативность

- `watch_folder` и `download_folder` в `torrclient.json` заданы относительно exe-бинарника —
  папка работает с любого диска, не зависит от текущего каталога и буквы диска.
- `cache_folder` и `data_folder` разводят одноразовое и постоянное: кэш
  (`tmdb-cache.json`, `torrclient.log`) можно положить на диск, который очищается при
  перезагрузке, — потерять его не страшно. Отметки просмотра и избранное лежат в
  `data_folder` и должны быть на постоянном диске. По умолчанию обе папки — каталог программы,
  так что обновление ничего не переносит. Меняются в «Настройки → Где хранятся данные».
- Web-интерфейс встроен в `torrclient.exe` (директива `//go:embed web`), поэтому папка `web/` не обязательна для запуска — нужна только для правки кода.
- Торрент-движок (TorrServer) ищется оболочкой рядом с собой — класть `TorrServer-windows-amd64.exe` и `torrclient.exe` в корень папки обязательно.
- Профиль TorrServer (`http://127.0.0.1:8090`) заводится оболочкой автоматически при запуске.

## На новом компьютере

1. Скопируйте папку целиком на любой диск (не обязательно D).
2. `TorrServer-windows-amd64.exe` должен быть доступен на запуск (иногда Windows блокирует скачанные exe — при необходимости разрешите в свойствах файла).
3. Плееры: пути VLC/PotPlayer/MPC задаются в «Настройки → Плееры» (кнопка «Найти плееры»). Путь из старого конфига (`E:\...\VLC\vlc.exe`) на новом ПК скорее всего не подойдёт — нажмите пересканирование.
4. Рекомендуется `start_desktop.bat` — оболочка сама поднимет TorrServer и демон.

## Пересборка

Сборка демона (нужен Go; модули подтянутся из сети; все кэши Go пишутся в `.go`, `.gocache`, `.gomods` внутри папки — на текущий диск):

```
build_daemon.bat
# или вручную (кэши на D):
set GOCACHE=D:\TorrClientPortable\.gocache
set GOMODCACHE=D:\TorrClientPortable\.gomods
go build -ldflags "-s -w" -o torrclient.exe .
```

Сборка десктоп-оболочки `app/` — `wails build` (нужны Wails CLI, Go с gcc/CGO и Node.js; `npm install` в `app/frontend`). Готовый `app\build\bin\TorrClient.exe` в сборку уже входит; иконка задана в `app\wails.json` (`build/bin/app.ico`). В `app/main.go` заложен защитник от повторного запуска (появляется только после пересборки).

## Что сознательно не копировали (генерируется/восстанавливается)

- `.go`, `.gocache`, `.gomods` — окружение сборки Go (кэш модулей, создаётся в папке при `build_daemon.bat`),
- `app\build\bin\.webview` — профиль WebView2 (пересоздаётся при запуске),
- `app\frontend\node_modules` — npm-зависимости (ставятся `npm install`),
- `torrclient.exe~` — резервная копия предыдущего бинарника.

`config.db` и `settings.json` в корне — данные самого TorrServer (создаются им при запуске). Их можно спокойно удалить — движок пересоздаст; удалять не обязательно, т.к. именно туда пишется история просмотра.

## Важно

- Избранное/закладки хранятся в `userdata.json`, отметки просмотра — в `viewed.json`; обе — в
  папке постоянных данных (`data_folder`, по умолчанию рядом с демоном). При смене папки файлы
  переносятся на новое место; то, что уже лежит в новой папке, не затирается.
- `torrclient.json` всегда остаётся рядом с демоном: в нём записаны обе папки, и другого места,
  откуда их можно было бы прочитать, нет.
- История просмотра (позиции файлов) живёт в самом TorrServer и хранится рядом с ним — для переноса вместе переносится и `TorrServer-windows-amd64.exe` с соседними данными программы.
